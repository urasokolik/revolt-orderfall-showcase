## Overview

**Revolt: Orderfall** is a mobile Unity game project built around short-form gameplay, scene-based progression, and a modular minigame structure. This repository is a public portfolio presentation of the project and its production scope.

The playable project is being developed with a focus on responsive mobile controls, repeatable gameplay loops, clear scene transitions, and monetization-ready ad placement.

## Highlights

- Multiple minigame experiences within one Unity project
- Scene-based progression and reusable game-management systems
- Rewarded and fullscreen advertising integration for Android
- Reusable UI and result-handling flow
- Mobile-first testing and release workflow
